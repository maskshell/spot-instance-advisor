# Release v1.0.3

**Release Date**: April 11, 2026

## 🆕 What's New

This is a bug fix release that resolves an issue where newer instance types were missing from query results due to incomplete API pagination.

## 🐛 Bug Fixes

### Fixed `DescribeInstanceTypes` API Pagination

The `DescribeInstanceTypes` API defaults to returning only 100 records per call. Previously, the tool made a single API call and only retrieved the first 100 instance types, causing newer instance types (e.g. `ecs.u2a-c1m2.xlarge`) to be silently truncated from results.

- **Added NextToken-based pagination loop** with `MaxResults=100` to retrieve ALL available instance types
- **Newer instance types now appear** in query results as expected
- **No behavior changes** for existing workflows — only more complete results

## 🔄 Migration Notes

This is a backward-compatible release. Existing scripts and workflows will continue to work without changes. You may notice additional instance types appearing in results that were previously missing due to the pagination limit.
